    광고

    사진 대표 색상은 어떻게 추출하나요?

    선택한 사진은 File API로 현재 브라우저에서 읽고 작은 분석용 Canvas로 축소합니다. 모든 원본 픽셀을 그대로 비교하면 모바일 기기의 메모리와 처리 시간이 커지므로 긴 변을 약 140픽셀로 줄여 표본을 만듭니다. 그 다음 투명 픽셀을 제외하고 RGB 값을 일정한 간격으로 묶어 비슷한 색을 같은 색상군으로 계산합니다. 등장 횟수가 많은 색상군부터 고르되 서로 지나치게 가까운 색은 건너뛰어 팔레트가 한 가지 계열로만 채워지는 것을 줄입니다.

    결과는 사진의 주제를 이해하는 인공지능 분류가 아니라 픽셀 빈도와 색상 거리 기반의 간단한 추정입니다. 그라데이션, 매우 어두운 그림자, 넓은 단색 배경이 있는 사진은 해당 색이 우선 선택될 수 있습니다. 원하는 수가 부족하면 남은 빈도 순서대로 채워 5~8개를 보여 줍니다. 각 팔레트 버튼을 누르면 HEX 하나를 복사하고 전체 복사는 RGB 값까지 함께 제공합니다.

    사용 방법

    이미지 선택

    JPG, PNG 또는 WebP 사진을 선택합니다. 파일은 업로드되지 않고 브라우저 메모리에서만 열립니다.

    색상 수 결정

    간단한 테마는 5개, 세부 강조색까지 보고 싶다면 7~8개를 선택해 추출 버튼을 누릅니다.

    HEX 복사

    결과 색상 카드를 클릭해 해당 HEX만 복사하거나 팔레트 전체를 텍스트로 복사합니다.

    실제 활용 사례

    여행 사진 카드

    바다와 하늘 사진에서 파랑 계열을 추출해 여행 앨범의 제목과 배경색을 맞춥니다.

    상품 상세페이지

    제품 사진의 주요 색을 찾아 배너와 설명 영역에 어울리는 보조색 후보로 활용합니다.

    인테리어 무드보드

    마음에 드는 공간 사진에서 벽, 가구와 소품의 색상 조합을 참고합니다.

    대표색은 픽셀을 일정 간격으로 읽고 비슷한 색을 묶은 뒤 많이 등장한 순서와 색상 간 거리를 함께 고려해 고릅니다. 따라서 작은 로고나 포인트 색은 사진에서 차지하는 면적이 작으면 빠질 수 있습니다. 색상 수를 5개와 8개로 바꾸어 비교하고 필요한 포인트 색은 사진 색상 추출 도구로 별도 확인하세요.

    주의사항

    추출 결과는 원본의 정확한 모든 색을 대표하지 않으며 사진 필터와 조명 영향을 그대로 받습니다. 브랜드 색상처럼 정확도가 중요한 경우 원본 디자인 파일의 공식 코드를 사용하세요. 저작권이나 개인정보가 있는 이미지는 본인이 사용할 권한이 있는지 확인해야 합니다.

    사진 팔레트 추출 FAQ

    사진이 서버에 업로드되나요?

    아니요. 이미지 읽기와 색상 계산은 현재 브라우저 안에서만 이루어집니다.

    왜 원본과 색이 조금 다른가요?

    비슷한 픽셀을 묶기 위해 RGB 값을 단순화하므로 대표 색은 원본의 한 픽셀과 다를 수 있습니다.

    투명 PNG도 분석할 수 있나요?

    예. 다만 투명도가 높은 픽셀은 대표 색상 집계에서 제외합니다.

    8개 색상이 모두 비슷하게 나옵니다.

    사진 대부분이 한 가지 색 계열이면 빈도가 높은 후보 역시 유사할 수 있습니다. 다른 부분을 자른 사진으로 다시 시도해 보세요.

    CMYK 인쇄 색으로 사용할 수 있나요?

    결과는 화면용 RGB 기반입니다. 인쇄에는 별도의 CMYK 변환과 색상 교정이 필요합니다.
