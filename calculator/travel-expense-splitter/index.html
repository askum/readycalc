여행 경비 분배 계산기

누가 얼마를 결제했는지 입력하면 모두가 똑같이 부담하도록 필요한 송금을 정리합니다.

쉼표로 구분해 주세요. 예: 민수, 지수, 하늘

한 줄에 “이름, 금액” 형식으로 입력하세요. 같은 사람이 여러 번 결제해도 됩니다.

결제 내역을 입력하고
정산 결과를 확인하세요.
동일 분배 결과

    광고 영역

    계산 기준과 활용법

    계산 기준

    모든 결제액을 더해 인원수로 똑같이 나눕니다. 더 낸 사람에게 덜 낸 사람이 보내도록 송금 횟수를 줄여 표시합니다.

    계산 예시

    세 명이 총 195,000원을 썼다면 1인당 65,000원입니다. 실제 결제액과의 차이만 송금합니다.

    주의사항

    특정 사람만 쓴 개인 비용은 먼저 제외하세요. 입력한 이름과 결제자 이름은 정확히 같아야 합니다.

    자주 묻는 질문

    결제 내역은 저장되나요?

    아닙니다. 이름과 결제금액은 현재 브라우저에서만 계산하며 localStorage나 공유 URL에 저장하지 않습니다. 필요한 경우 정리된 결과 텍스트만 복사하세요.

    여러 번 결제한 사람은 어떻게 입력하나요?

    같은 이름으로 줄을 추가하면 금액을 합산합니다.

    사람마다 부담 비율이 다르면요?

    현재 도구는 동일 분배 전용입니다. 어린이 할인이나 개인 비용은 분배 전에 별도로 조정해 주세요.
