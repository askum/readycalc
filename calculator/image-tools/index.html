    이미지 크기 변경과 압축 원리

    이미지 크기 변경은 사진을 이루는 가로·세로 픽셀 수를 새 값으로 다시 계산하는 작업입니다. 예를 들어 4,000×3,000픽셀 사진을 1,200×900픽셀로 줄이면 화면에 그려야 할 픽셀이 약 1,200만 개에서 108만 개로 감소합니다. 같은 파일 형식과 비슷한 품질이라면 픽셀 수가 줄어든 만큼 파일 용량도 대체로 작아집니다. ‘원본 가로세로 비율 유지’를 선택하면 가로 또는 세로 중 하나를 변경할 때 다른 값이 자동으로 계산되어 사진이 눌리거나 늘어나는 현상을 예방합니다.

    이미지 압축은 저장 형식과 품질 값에 따라 결과가 달라집니다. JPG와 WebP는 사람의 눈에 덜 민감한 세부 정보를 일부 줄이는 손실 압축을 지원하므로 품질을 낮추면 보통 파일 크기가 작아집니다. 품질 82%는 웹 게시용 사진의 출발점으로 사용할 수 있지만 작은 글자, 도면, 제품 라벨처럼 선명한 경계가 중요한 이미지는 더 높은 값을 권장합니다. PNG는 픽셀을 손실 없이 저장하는 형식이라 품질 슬라이더가 적용되지 않습니다. PNG 용량을 줄이려면 가로·세로 크기를 줄이거나 사진인 경우 JPG·WebP로 바꾸는 편이 효과적입니다.

    JPG를 PNG로 변환할 때 알아둘 점

    저장 형식에서 ‘PNG로 변환’을 고르면 JPG 사진을 브라우저의 Canvas에 그린 뒤 PNG 파일로 다시 저장합니다. 확장자 이름만 바꾸는 방식이 아니라 실제 이미지 데이터가 PNG로 인코딩됩니다. 다만 JPG에서 이미 압축으로 사라진 세부 정보가 PNG 변환으로 복구되지는 않습니다. 사진은 PNG로 바꾸면 오히려 용량이 커질 수 있으며, 투명 배경이 필요하거나 로고·도형·화면 캡처처럼 경계가 분명한 이미지에 PNG가 적합합니다. 반대로 PNG의 투명 영역을 JPG로 저장하면 투명도를 표현할 수 없어 흰색 배경으로 채웁니다.

    회전은 오른쪽 90도, 180도, 왼쪽 90도를 지원합니다. 90도 또는 270도 회전하면 최종 파일의 가로와 세로 크기가 서로 바뀝니다. 좌우 뒤집기는 거울처럼 수평 방향을 반전하고, 상하 뒤집기는 위아래 방향을 반전합니다. 회전과 뒤집기를 동시에 선택할 수도 있으므로 셀카 방향 수정, 스캔 문서 바로 세우기, 제품 사진의 방향 통일에 활용할 수 있습니다. 처리 후 미리보기와 최종 픽셀 크기를 확인한 다음 파일을 내려받으세요.

    선택한 원본 파일과 결과 이미지는 생활계산소 서버로 업로드되지 않습니다. 파일 읽기, 리사이즈, 회전, 압축과 형식 변환은 현재 브라우저의 Canvas API에서 실행됩니다. localStorage에는 저장 형식, 압축 품질, 비율 유지와 회전·뒤집기 같은 사용자 설정만 보관하며 이미지 파일과 미리보기는 저장하지 않습니다. 탭을 닫거나 새로 고치면 결과가 사라지므로 필요한 파일은 반드시 다운로드하세요. 25MB 또는 4,000만 화소를 넘는 이미지는 모바일 기기의 메모리 부족과 브라우저 중단을 줄이기 위해 제한합니다.

    이미지 도구 사용 예시

    블로그 사진 크기 줄이기

    4,032×3,024px 스마트폰 사진의 가로를 1,200px로 입력하고 비율 유지를 켜면 세로가 자동 계산됩니다. JPG 품질 80~85%부터 비교해 보세요.

    JPG 로고를 PNG로 저장

    JPG 파일을 선택하고 ‘PNG로 변환’을 지정하면 실제 PNG 데이터로 저장됩니다. 원본 JPG의 배경이 자동으로 투명해지는 기능은 아닙니다.

    옆으로 누운 사진 바로 세우기

    오른쪽 또는 왼쪽 90도 회전을 선택해 처리합니다. 필요하면 좌우 뒤집기를 함께 적용하고 미리보기에서 글자 방향을 확인하세요.

    이미지 크기 변경·압축 FAQ

    이미지가 서버로 업로드되나요?

    아닙니다. 파일 선택부터 변환과 미리보기 생성까지 현재 브라우저에서만 처리합니다. 이미지 파일을 서버나 localStorage에 저장하지 않습니다.

    JPG를 PNG로 바꾸면 화질이 좋아지나요?

    아닙니다. PNG로 다시 저장해도 JPG 압축 과정에서 이미 사라진 정보는 복구되지 않습니다. 사진은 파일 용량이 더 커질 수도 있습니다.

    이미지 압축 품질은 몇 퍼센트가 적당한가요?

    일반 웹 사진은 75~85%에서 시작해 결과를 비교해 보세요. 작은 글자나 선이 중요한 이미지는 90% 이상 또는 PNG가 더 적합할 수 있습니다.

    PNG에서 압축 품질을 선택할 수 없는 이유는 무엇인가요?

    브라우저 Canvas의 PNG 저장은 무손실 방식이며 JPG·WebP와 같은 손실 품질 값을 사용하지 않습니다. 픽셀 크기를 줄이면 PNG 용량을 줄이는 데 도움이 됩니다.

    회전하면 가로와 세로 입력값도 바뀌나요?

    입력값은 회전 전 크기를 나타냅니다. 90도 또는 270도로 처리한 최종 파일은 가로와 세로가 서로 바뀌며 결과 카드에 최종 크기가 표시됩니다.

    용량이 원본보다 커질 수도 있나요?

    그럴 수 있습니다. JPG를 PNG로 바꾸거나 품질을 높여 다시 저장하면 용량이 증가할 수 있습니다. 결과 카드에서 원본과 결과 용량을 비교하세요.

    움직이는 GIF나 HEIC 사진도 지원하나요?

    현재는 JPG, PNG, WebP 정지 이미지만 지원합니다. 애니메이션 WebP는 첫 화면만 처리될 수 있으므로 사용하지 마세요. HEIC와 GIF는 지원 대상이 아닙니다.
