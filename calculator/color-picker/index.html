온라인 색상 선택기

기기의 기본 컬러 피커에서 색을 고르면 HEX, RGB와 HSL 코드가 즉시 표시됩니다.

색상 영역을 클릭하거나 키보드로 초점을 옮긴 뒤 Enter 또는 Space 키를 사용하세요.

선택한 색상

    광고

    색상 선택기는 어떻게 작동하나요?

    이 페이지는 브라우저가 제공하는 HTML color 입력을 사용합니다. 색상 영역을 누르면 운영체제와 브라우저에 맞는 컬러 선택창이 열리고, 선택한 값은 표준 6자리 HEX 코드로 전달됩니다. 생활계산소는 이 값을 빨강·초록·파랑의 0~255 숫자로 풀어 RGB를 만들고, 가장 큰 채널과 작은 채널의 차이를 이용해 HSL의 색상각·채도·명도를 계산합니다. 외부 팔레트 서비스나 색상 API에 값을 보내지 않습니다.

    색상 선택창의 모양과 기능은 Safari, Chrome, 모바일 브라우저마다 다릅니다. 일부 데스크톱 환경은 화면의 특정 색을 집는 스포이트 기능을 제공하지만 모든 브라우저에서 보장되지는 않습니다. 선택 결과의 HEX, RGB, HSL 버튼을 각각 누르면 해당 코드만 복사되고, 아래 전체 복사 버튼은 세 형식을 함께 복사합니다.

    사용 방법

    색상 열기

    큰 색상 입력 영역을 누릅니다. 키보드 사용자는 Tab으로 이동한 뒤 Enter나 Space로 선택창을 열 수 있습니다.

    색상 조절

    기기의 색상환, 슬라이더 또는 숫자 입력을 이용해 원하는 색을 고르면 페이지 미리보기가 실시간으로 바뀝니다.

    코드 복사

    HEX, RGB, HSL 중 필요한 표시값을 누르거나 전체 복사 버튼을 사용해 CSS와 디자인 문서에 붙여 넣습니다.

    실제 활용 사례

    웹 버튼 색상

    버튼 배경을 눈으로 고른 다음 HEX를 복사해 CSS의 background-color 속성에 적용합니다.

    SNS 카드 제작

    사진이나 글자와 어울리는 배경색을 선택하고 RGB 값을 이미지 편집 도구에 옮깁니다.

    테마 색상 기록

    같은 색의 HSL 값을 확인해 명도와 채도만 다르게 조절할 수 있는 기준을 마련합니다.

    선택한 색을 실제 화면에 적용할 때는 기본색 하나만 정하기보다 hover, focus, disabled 상태와 밝고 어두운 배경에서의 대비도 함께 시험하는 것이 좋습니다. HEX, RGB와 HSL은 표현 방식만 다를 뿐 같은 화면 색을 가리키므로 협업 문서에서는 한 형식을 기준으로 정하면 혼선을 줄일 수 있습니다.

    주의사항

    모니터 밝기, 야간 모드와 색상 프로필에 따라 실제로 보이는 색은 달라질 수 있습니다. 인쇄 작업은 RGB가 아닌 CMYK 교정이 필요할 수 있습니다. 마지막으로 고른 색상만 현재 브라우저 설정에 저장되며 개인정보나 계정 정보와 연결되지 않습니다.

    색상 선택기 FAQ

    스포이트가 보이지 않는 이유는 무엇인가요?

    스포이트 제공 여부는 운영체제와 브라우저 기능에 따라 다르며 페이지가 직접 추가할 수 없습니다.

    HEX와 RGB는 같은 색인가요?

    예. 서로 다른 표기일 뿐이며 같은 sRGB 색상을 나타낼 수 있습니다.

    투명 색상을 고를 수 있나요?

    기본 color 입력은 불투명 색상을 반환하므로 알파 투명도는 별도로 지정해야 합니다.

    선택한 값이 실시간으로 바뀌나요?

    예. 색상을 조절하는 동안 input 이벤트를 받아 세 코드와 미리보기를 갱신합니다.

    색상이 서버로 전송되나요?

    아니요. 모든 변환은 브라우저에서 실행되며 마지막 색상만 기기 설정으로 저장됩니다.
