Bytes made clear

파일 용량 단위 변환

Byte, KB, MB, GB, TB와 KiB, MiB, GiB를 한 번에 환산하고 두 기준의 차이를 확인하세요.

값과 단위를 선택하면 다른 모든 단위로 바꿉니다.
변환 결과

    광고

    KB와 KiB는 왜 다른가요?

    파일 용량의 가장 작은 기본 단위는 Byte입니다. 국제단위계에 맞춘 십진 표기에서 1KB는 1,000Byte, 1MB는 1,000KB, 1GB는 1,000MB입니다. 저장장치 제조사와 통신 속도 표기에서 주로 이 기준을 사용합니다. 반면 컴퓨터 메모리처럼 2의 거듭제곱을 사용하는 환경에서는 1KiB가 1,024Byte, 1MiB가 1,024KiB, 1GiB가 1,024MiB입니다. IEC가 혼동을 줄이기 위해 KiB, MiB, GiB라는 이름을 정의했습니다.

    예를 들어 제조사가 1GB라고 표기한 1,000,000,000Byte는 이진 단위로 약 0.931GiB입니다. 운영체제가 이진 계산을 하면서 화면에는 GB라고 표시하면 사용자가 예상한 숫자보다 작아 보일 수 있습니다. 이 변환기는 모든 값을 먼저 정확한 Byte 수로 바꾼 뒤 각 단위의 바이트 수로 나누며 최대 유효 숫자 12자리 범위에서 읽기 쉽게 표시합니다.

    사용 방법

    숫자 입력

    파일 또는 저장장치에 표시된 용량을 입력합니다. 소수도 사용할 수 있으며 음수 용량은 허용하지 않습니다.

    기준 단위 선택

    표시에 KB처럼 B가 붙는지, KiB처럼 iB가 붙는지 확인하고 정확한 현재 단위를 고릅니다.

    결과 비교

    변환하면 Byte부터 TB와 GiB까지 한 번에 표시되어 십진·이진 단위를 함께 비교할 수 있습니다.

    실제 활용 사례

    저장장치 용량

    1TB SSD가 운영체제에서 약 931GiB로 보이는 이유를 수치로 확인합니다.

    업로드 제한

    서비스가 10MB 제한을 안내할 때 파일 정보가 MiB로 표시된다면 Byte 기준으로 비교합니다.

    서버 메모리

    메모리 할당량 512MiB가 십진 MB로는 얼마인지 변환해 문서 표기를 통일합니다.

    전송 시간을 계산하려면 파일 용량의 Byte와 통신 속도의 bit를 구분해야 합니다. 일반적으로 1Byte는 8bit지만 네트워크 프로토콜 오버헤드와 실제 속도 저하가 있어 단순히 8로 나눈 시간과 일치하지 않습니다. 이 페이지는 저장 용량 단위 변환에 집중하며 다운로드 시간은 계산하지 않습니다.

    주의사항

    일부 운영체제와 앱은 실제로 1024 단위를 계산하면서도 MB나 GB라고 표시하므로 화면의 단위 이름만으로 기준을 확정하기 어렵습니다. 정확한 비교가 필요하면 속성 창이나 기술 문서에서 Byte 원값을 확인하세요. 압축 파일의 용량은 압축 해제 후 달라질 수 있습니다.

    광고

    파일 용량 변환 FAQ

    1MB는 몇 Byte인가요?

    십진 단위의 1MB는 1,000,000Byte입니다. 1MiB는 1,048,576Byte입니다.

    1GB가 1024MB 아닌가요?

    표준 십진 GB는 1000MB입니다. 1024MiB는 1GiB라고 구분해 쓰는 것이 정확합니다.

    왜 SSD 용량이 작게 보이나요?

    제조사는 십진 GB를, 일부 운영체제는 이진 환산값을 사용하기 때문입니다.

    비트(bit)도 변환하나요?

    현재 페이지는 파일 저장 용량인 Byte 단위만 제공합니다. 1Byte는 일반적으로 8bit입니다.

    입력값이 저장되나요?

    아니요. 계산은 현재 브라우저에서 실행되며 용량 숫자를 저장하거나 전송하지 않습니다.
