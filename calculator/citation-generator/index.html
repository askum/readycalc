참고문헌 생성기

도서, 학술논문 또는 웹사이트의 서지 정보를 APA·MLA·Chicago 형식의 참고문헌 초안으로 정리합니다.

출처에 표시된 정보를 그대로 확인해 입력하세요.
선택한 인용 형식

    광고

    참고문헌 형식이 필요한 이유

    참고문헌은 보고서, 논문과 발표 자료에서 어떤 자료를 참고했는지 독자가 다시 확인할 수 있게 만드는 기록입니다. APA, MLA, Chicago는 저자, 연도, 제목, 출판 정보의 순서와 구두점이 서로 다릅니다. APA는 사회과학 분야에서 저자와 연도를 강조하고, MLA는 인문학 분야에서 저자와 작품 제목을 중심으로 구성하며, Chicago는 역사·출판 분야에서 자주 쓰입니다. 이 생성기는 입력값을 대표적인 기본 순서로 배열해 초안을 빠르게 만드는 데 목적이 있습니다.

    자료 유형을 먼저 고르면 그 유형에 필요한 입력칸만 표시됩니다. 저자명은 원하는 스타일의 관례에 맞게 입력해야 하며, 여러 저자, 편집자, 번역자, DOI, 판차와 온라인 선공개 같은 복잡한 조건은 자동 판단하지 않습니다. 외부 DOI API나 서지 데이터베이스를 호출하지 않으므로 오탈자를 보정하거나 출처의 진위를 확인하지 않습니다. 결과는 반드시 학교, 학회, 출판사 또는 담당 교수가 제공한 최신 지침과 대조하세요.

    사용 방법

    자료 유형 선택

    책은 도서, 저널에 실린 연구는 학술논문, 일반 온라인 문서는 웹사이트를 선택합니다.

    서지 정보 입력

    표지·판권지·논문 첫 페이지·웹페이지의 저자와 제목, 발행연도, 출판 정보를 확인합니다.

    형식 선택과 검토

    요구된 APA, MLA 또는 Chicago를 선택해 생성한 뒤 이탤릭체와 대소문자 등 세부 규정을 검토합니다.

    실제 활용 사례

    대학 과제

    교재와 참고 도서를 같은 스타일로 정리해 보고서 말미의 참고문헌 목록 초안을 만듭니다.

    학술 자료 정리

    학술지명, 권·호, 페이지를 입력해 읽은 논문의 출처를 일관된 순서로 기록합니다.

    웹 자료 인용

    기관명, 페이지 제목, URL과 접속일을 함께 기록해 변경될 수 있는 웹 출처를 식별합니다.

    주의사항

    스타일 매뉴얼은 판본에 따라 달라지고 기관별 예외 규칙도 있습니다. 한글 저자명과 영문 저자명의 성·이름 순서, 두 명 이상의 저자 표기, 제목의 이탤릭체, DOI, 발행일이 없는 자료 표기, 각주와 참고문헌의 차이는 별도로 확인해야 합니다. 생성 결과를 그대로 제출하기 전에 원문 정보와 요구 지침을 한 번 더 대조하세요.

    참고문헌 생성기 FAQ

    APA 7판을 완전히 지원하나요?

    일반적인 기본 순서를 제공하지만 모든 예외를 처리하지 않으므로 제출 기관의 APA 7판 지침을 확인해야 합니다.

    DOI를 자동으로 찾나요?

    아니요. 외부 API를 사용하지 않으며 사용자가 입력한 정보만 정리합니다.

    여러 명의 저자는 어떻게 입력하나요?

    요구 스타일의 저자 연결 규칙에 맞춰 직접 입력하세요. 자동으로 저자 순서를 바꾸지는 않습니다.

    결과가 저장되나요?

    아니요. 입력과 결과는 현재 브라우저에서만 처리되며 서버로 전송하지 않습니다.

    인용과 참고문헌은 같은가요?

    본문 인용은 글 안의 짧은 표시이고 참고문헌은 글 끝의 상세 출처 목록입니다. 이 도구는 참고문헌 항목 초안을 만듭니다.
