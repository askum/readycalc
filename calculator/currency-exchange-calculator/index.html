환전 계산기

은행이나 환전소에서 확인한 환율과 우대 조건을 입력해 실제 수령할 외화를 계산하세요.

실시간 환율 API를 사용하지 않습니다. 금융기관에서 확인한 값을 입력하세요.

환율과 금액을 입력하고
계산 버튼을 눌러주세요.

    환전 수수료와 우대율 계산 원리

    환전소에서 보이는 기준환율과 실제 외화를 살 때 적용되는 현찰 매도율은 같지 않습니다. 금융기관은 기준환율에 환율 스프레드를 더해 외화를 판매하며, 환율 우대는 이 스프레드 부분을 일정 비율 깎아 주는 방식입니다. 예를 들어 기준환율이 1달러에 1,400원이고 현찰 스프레드가 1.75%, 우대율이 90%라면 전체 1.75%가 없어지는 것이 아니라 스프레드의 90%가 할인됩니다. 남는 스프레드는 1.75% × 10%인 0.175%이고 계산상 적용 환율은 약 1,402.45원이 됩니다.

    계산기는 먼저 환전할 원화에서 별도 고정 수수료를 빼고, 기준환율에 할인 후 스프레드를 더한 적용 환율을 만듭니다. 남은 원화를 적용 환율로 나눈 다음 환율 표시 단위를 곱해 예상 외화 수령액을 계산합니다. 일본 엔이나 베트남 동처럼 금융기관이 100단위 환율을 표시하는 경우 ‘외화 100단위당’을 선택해야 합니다. 단위 선택이 틀리면 결과가 100배 달라질 수 있으므로 환율표의 표기 단위를 반드시 확인하세요.

    이 도구는 실시간 환율 API를 사용하지 않기 때문에 사용자가 입력한 환율로만 계산합니다. 실제 창구나 앱에서는 최소 수수료, 권종별 재고, 소수점 절사, 환전 장소별 추가 비용이 적용될 수 있습니다. 신용카드 결제 환율은 현찰 환율과 다른 전신환 매도율 및 카드사 적용일을 사용하므로 현금 환전 계산과 동일하게 보지 않아야 합니다. 큰 금액은 여러 금융기관의 최종 수령액을 직접 비교하고 환율 변동 위험도 고려하세요. 결과는 일반적인 추정치이며 금융상품 추천이나 미래 환율 예측이 아닙니다.

    여러 번 나누어 환전할 때는 각 거래의 환율과 수수료를 따로 계산한 뒤 수령 외화를 합산하세요. 실제 지출 원화 총액을 받은 외화 총액으로 나눈 실질 환율이 비교에 더 유용합니다.

    환전 계산 예시

    100만원을 달러로 환전

    환율 1,400원, 스프레드 1.75%, 우대 90%라면 적용 환율은 약 1,402.45원이며 약 713.04달러입니다.

    50만원을 엔화로 환전

    100엔당 950원을 입력하고 표시 단위를 100으로 선택하면 수수료 전 약 52,632엔으로 환산됩니다.

    고정 수수료가 있는 경우

    30만원에서 수수료 5천원을 먼저 빼고 남은 29만5천원을 적용 환율로 나누어 수령액을 계산합니다.

    환전 계산기 FAQ

    실시간 환율이 자동으로 들어오나요?

    아닙니다. 외부 API를 사용하지 않으므로 은행이나 환전소의 환율을 직접 입력해야 합니다.

    환율 우대 90%는 환율을 90% 할인한다는 뜻인가요?

    아닙니다. 일반적으로 기준환율과 현찰 환율 사이의 스프레드 중 90%를 할인한다는 뜻입니다.

    일본 엔은 왜 100단위를 선택하나요?

    국내 환율표에서 100엔당 원화로 표시하는 경우가 많기 때문입니다. 실제 환율표 단위를 확인하세요.

    카드 결제 금액도 계산할 수 있나요?

    이 도구는 현금 환전 중심입니다. 해외 카드 수수료까지 포함하려면 해외여행 경비 계산기를 이용하세요.

    입력한 환율은 저장되나요?

    자동 복원을 위해 현재 브라우저에만 저장되고 서버로 전송되지 않습니다.

    계산 결과와 실제 수령액이 다른 이유는 무엇인가요?

    금융기관의 반올림, 최소 수수료, 권종과 환전 방식에 따라 차이가 생길 수 있습니다.
