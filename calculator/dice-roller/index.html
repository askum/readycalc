    온라인 주사위의 난수 생성 원리

    이 도구는 Math.random() 대신 브라우저의 Web Crypto API인 crypto.getRandomValues()를 사용합니다. 운영체제가 제공하는 보안 난수원을 바탕으로 32비트 숫자를 만들고, 선택한 면 수로 나눌 때 특정 결과가 더 자주 나오는 모듈로 편향을 피하도록 허용 범위를 벗어난 값은 다시 뽑습니다. d6은 1~6, d20은 1~20 사이의 모든 면이 같은 확률을 갖도록 계산합니다.

    주사위를 여러 개 선택하면 각 주사위에 대해 독립적으로 난수를 만들고 개별 결과, 합계, 최솟값과 최댓값을 보여 줍니다. 한 번의 결과가 연속으로 같거나 특정 숫자가 자주 나오는 것은 무작위 과정에서 자연스럽게 발생할 수 있습니다. 작은 횟수에서 모든 면이 고르게 등장할 것이라고 기대해서는 안 됩니다.

    사용 방법

    면 수 선택

    보드게임 규칙에 맞게 d6, d8, d10, d12 또는 d20을 선택합니다.

    개수 입력

    한 번에 굴릴 주사위를 1~20개로 입력합니다. 합계가 필요한 공격 판정 등에도 사용할 수 있습니다.

    결과 확인

    개별 눈과 합계를 확인하고 필요하면 결과 텍스트를 복사하거나 공유합니다.

    구체적인 상황으로 이해하는 활용 예시

    다음 세 상황은 도구의 처리 과정과 결과 해석을 설명하기 위한 가상 예시입니다. 입력 조건을 바꾸면 결과도 달라지므로 자신의 조건과 비교해 확인하세요.

    1. 6면체 두 개의 합계를 읽는 경우

    d6 두 개를 굴렸을 때 가상 결과가 2와 5라면 합계는 7, 최솟값은 2, 최댓값은 5입니다. 두 주사위의 가능한 조합은 36개이며 합계 7은 그중 6개 조합에서 나옵니다. 모든 합계가 같은 확률은 아니고 다음 실행이 반드시 7이나 이전과 다른 값으로 나오는 것도 아닙니다.

    2. 20면체 한 개로 판정하는 경우

    d20 한 개의 값은 1부터 20까지이고 특정 면 하나의 이론상 확률은 1/20입니다. 가상 결과 14에 게임 규칙상 보정치 3을 더한다면 최종 판정은 17이지만 도구는 그 보정치를 자동으로 더하지 않습니다. 결과의 원래 주사위 값과 외부 규칙에 따른 판정값을 따로 기록하세요.

    3. 6면체 세 개를 함께 굴리는 경우

    가상 결과 1·4·6이면 합계는 11입니다. 세 개의 d6 합계는 최소 3, 최대 18 범위이고 개별 주사위는 각각 새 난수로 결정합니다. 같은 수가 연속해서 나오거나 합계가 반복되어도 무작위 과정에서 가능합니다. 여기에 적힌 수치는 결과 읽기 예시이며 실제 실행 순서를 예측하지 않습니다.

    여러 개를 선택하면 각 주사위 결과와 합계를 함께 표시하므로 보드게임의 이동 거리, 역할극의 능력 판정과 순서 정하기에 활용할 수 있습니다. 같은 조건으로 다시 굴려도 결과가 달라지는 것이 정상입니다. 규칙상 보정치나 가장 높은 값만 선택해야 한다면 화면의 개별 결과를 기준으로 사용자가 직접 적용해야 합니다. 결과를 기록할 때는 주사위 종류와 개수도 함께 적으세요.

    주의사항

    이 결과는 일반 게임과 순서 정하기를 위한 도구입니다. 실제 금전이 오가는 도박, 추첨 인증이나 법적 공정성이 필요한 절차에는 사용하지 마세요. 브라우저와 기기의 보안 환경이 손상된 경우 난수 품질도 보장할 수 없습니다.

    온라인 주사위 FAQ

    각 숫자의 확률은 같은가요?

    모듈로 편향을 제거한 crypto 난수를 사용해 각 면이 같은 확률이 되도록 구현했습니다.

    왜 같은 숫자가 연속으로 나오나요?

    무작위 결과에서도 반복은 정상적으로 생길 수 있으며 이전 결과가 다음 결과에 영향을 주지 않습니다.

    최대 몇 개를 굴릴 수 있나요?

    화면 가독성과 일반 게임 용도를 고려해 한 번에 20개로 제한합니다.

    인터넷 연결이 필요한가요?

    페이지가 열린 뒤 난수 계산은 브라우저에서 이루어지며 외부 API를 호출하지 않습니다.

    공식 추첨에 사용할 수 있나요?

    아니요. 감사 기록과 제3자 검증이 필요한 공식 추첨에는 인증된 전문 시스템을 사용하세요.
