MB와 MiB는 왜 다를까: 저장 용량과 업로드 제한 읽는 법

10진법 KB·MB와 2진법 KiB·MiB를 실제 숫자로 환산하고 파일 크기 제한을 확인하는 요령입니다.

생활계산소 · 2026년 10월 5일

같은 바이트 수를 다른 기준으로 읽기

파일 크기의 공통 출발점은 바이트(B)입니다. 십진 접두어에서 1KB는 1,000B, 1MB는 1,000,000B입니다. 이진 접두어에서 1KiB는 1,024B, 1MiB는 1,048,576B입니다. 표기의 i 한 글자가 기준을 바꿉니다. IEC의 단위 안내도 KiB와 MiB를 각각 1,024와 그 제곱에 해당하는 이진 접두어로 구분합니다. 파일이 바뀐 것이 아니라 같은 바이트 수를 표현하는 눈금이 다른 것입니다.

예를 들어 크기가 정확히 10,000,000B인 파일은 10MB이면서 약 9.5367MiB입니다. 숫자만 보면 10보다 9.54가 작아 보여도 두 값은 같은 파일을 가리킵니다. 다운로드 창, 운영체제, 클라우드 서비스가 어느 기준을 쓰는지 표시하지 않으면 혼동하기 쉽습니다. 제품 광고의 저장 공간과 컴퓨터 화면의 숫자를 비교할 때도 먼저 단위를 확인하세요.

업로드 제한을 넘는지 직접 계산해 보기

업로드 제한이 ‘10MB’라고 명시됐고 서비스가 십진 기준을 쓴다면 최대 10,000,000B입니다. 파일이 10.2MB라면 약 10,200,000B이므로 200,000B를 줄여야 합니다. 반면 같은 서비스가 내부적으로 10MiB를 기준으로 구현했다면 허용 바이트 수는 10,485,760B입니다. 화면에 단위 기준이 명시되지 않은 경우에는 최종 업로드 결과가 우선이며, 경계에 딱 맞춘 파일보다 여유를 둔 파일이 실패를 줄일 수 있습니다.

이미지 4개가 각각 2.4MB라면 단순 합계는 9.6MB입니다. 서비스가 파일별 3MB와 전체 10MB를 동시에 제한한다면 각 파일과 전체 합계가 모두 조건을 만족하는지 확인해야 합니다. 한 파일만 3.1MB이면 전체가 10MB보다 작아도 업로드가 거부될 수 있습니다. 이메일 첨부처럼 전송 과정에서 인코딩이나 별도 제한이 생기는 경우에는 화면에 표시된 파일 크기만으로 결과를 보장할 수 없습니다.

사진·영상과 저장 장치에서 단위를 구분하기

같은 사진을 압축해 5MB에서 3MB로 줄였다면 십진 기준으로 2,000,000B, 약 1.907MiB가 감소한 셈입니다. 서로 다른 단위의 숫자를 그냥 빼지 말고 바이트로 맞춘 뒤 차이를 계산하세요. 영상 저장 공간을 추정할 때도 먼저 한 파일의 바이트 수와 예상 파일 개수를 곱한 뒤 MB·GB 또는 MiB·GiB로 환산하면 기준을 섞을 위험이 줄어듭니다.

저장 장치의 사용 가능 공간은 운영체제 파일, 포맷 방식, 예약 영역과 단위 표기 차이까지 영향을 받습니다. 표기된 총용량을 파일 저장 가능량으로 그대로 가정하지 마세요. 생활계산소 변환기는 숫자와 단위 사이의 수학적 환산만 수행하며 장치의 실제 빈 공간이나 서비스의 업로드 정책을 읽지는 않습니다.

표를 읽을 때 빠뜨리기 쉬운 점

대문자 B는 바이트, 소문자 b는 비트로 쓰이는 경우가 많습니다. 인터넷 속도 표기의 Mb/s와 파일 크기의 MB는 같은 단위가 아닙니다. 이 도구는 바이트 기반 용량 단위의 환산에 초점을 맞추므로 네트워크 전송 시간까지 예측하지 않습니다. 파일 크기 표시가 반올림된 숫자라면 경계값을 판단할 때 원본 파일의 정확한 바이트 수를 확인하는 편이 안전합니다.

다운로드 시간은 파일 용량만으로 정해지지 않습니다

파일이 100MB라고 적혀 있어도 인터넷 연결 속도가 100Mb/s라면 숫자 100이 같다고 1초에 내려받는다는 뜻이 아닙니다. 1바이트는 8비트이므로 100MB는 약 800Mb의 데이터에 해당합니다. 이상적인 조건에서 100Mb/s로 나누면 8초지만 실제 전송은 프로토콜 오버헤드, 서버 속도, 네트워크 혼잡 등으로 더 오래 걸립니다. 이 도구는 단위를 바꿔 주는 계산기이므로 실제 다운로드 시간을 예측하는 값과는 구분하세요.

정기적으로 파일을 백업할 공간을 계획한다면 가장 큰 파일 하나가 아니라 예상 파일 수와 성장량을 곱해야 합니다. 매달 500MB씩 사진이 늘어난다고 가정하면 1년 추가량은 6GB, 약 5.59GiB입니다. 중복본, 썸네일, 앱 데이터와 여유 공간까지 고려하면 정확히 6GB짜리 저장 장치로 충분하다고 말할 수 없습니다. 숫자 변환은 출발점이며 실제 서비스의 저장 정책을 확인해야 합니다.

자주 묻는 질문

1MB는 1,024KB인가요?

십진 기준으로는 1MB=1,000KB입니다. 이진 기준은 1MiB=1,024KiB로 표기합니다.

10MB와 10MiB는 같은 크기인가요?

아닙니다. 각각 10,000,000B와 10,485,760B로 약 4.86% 차이가 납니다.

업로드 제한이 MB만 적혀 있으면요?

서비스의 도움말에서 기준을 확인하고, 애매하면 제한보다 충분히 작은 파일을 준비하세요.

파일을 압축하면 바이트 수도 정확히 비례해 줄어드나요?

아닙니다. 압축 형식과 파일 내용에 따라 결과가 달라지므로 변환 후 실제 파일 크기를 확인해야 합니다.
