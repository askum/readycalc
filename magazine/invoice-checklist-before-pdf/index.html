견적서와 청구서를 PDF로 보내기 전 확인할 항목

공급자·고객 정보, 품목·수량·단가·부가세와 지급 조건을 확인하고 인쇄용 문서의 오류를 줄이는 실전 점검표입니다.

생활계산소 · 2026년 10월 25일

견적서와 청구서의 목적을 먼저 구분합니다

견적서는 거래 전에 제공 범위와 예상 금액, 유효기간과 조건을 제안하는 문서입니다. 청구서는 합의된 거래에 대해 지급을 요청하는 문서이므로 납품 또는 작업 기준, 지급기한과 입금 정보를 더 명확히 적어야 합니다. 문서 종류를 잘못 선택하면 상대방이 금액의 확정 여부를 오해할 수 있습니다.

간단 생성기는 두 문서의 기본 틀과 금액 합계를 만드는 도구입니다. 계약 성립, 전자서명, 세금계산서 발행이나 회계 시스템 등록을 자동으로 처리하지 않습니다. 거래 규모와 법적 요구사항에 맞는 별도 계약서와 증빙이 필요한지 확인하세요.

당사자와 문서 식별정보를 검토합니다

공급자와 고객의 상호, 담당자, 연락처와 주소 중 거래에 필요한 항목을 정확히 적습니다. 사업자등록번호나 계좌번호처럼 중요한 정보는 이전 문서에서 무심코 복사하지 말고 최신 원본과 대조하세요. 문서번호를 연도와 순번으로 관리하면 수정본과 거래 내역을 찾기 쉽습니다.

작성일, 견적 유효기간, 납품 예정일과 지급기한은 서로 다른 날짜입니다. 비고에 한 줄로 섞지 말고 의미가 드러나도록 구분하세요. 수정본을 보낼 때에는 기존 문서번호와 버전, 변경된 항목을 알려 상대방이 오래된 파일을 사용하지 않게 해야 합니다.

품목·수량·단가의 기준을 통일합니다

품목명은 상대방이 제공 범위를 이해할 수 있을 만큼 구체적으로 적고 수량의 단위를 명확히 합니다. 시간, 건, 세트처럼 단위가 다르면 단가가 무엇을 기준으로 하는지 함께 표시하세요. 할인이나 배송비가 있다면 품목에 포함했는지 별도 항목인지 문서 전체에서 일관되게 처리합니다.

여러 품목을 입력한 뒤 공급가액 합계를 수기로 한 번 더 확인하세요. 소수 수량, 반올림과 최소 작업비가 있는 거래는 단순 수량 곱셈과 다를 수 있습니다. 생성된 합계가 실제 합의와 일치하는지 확인한 뒤에만 PDF를 저장합니다.

부가세 표시는 실제 거래 조건에 맞춥니다

도구의 10% 별도 선택은 품목 합계에 10%를 추가하는 단순 계산입니다. 거래가 실제 과세 대상인지, 면세인지, 단가에 세금이 이미 포함됐는지는 사용자가 확인해야 합니다. 포함 가격을 입력하고 다시 10%를 더하면 총액이 잘못될 수 있으므로 계약과 견적 기준을 먼저 통일하세요.

이 문서는 법정 세금계산서나 현금영수증을 발행하지 않습니다. 공급가액과 세액의 공식 증빙이 필요한 거래는 국세청의 발행 절차와 보관 의무를 따라야 합니다. 세무 처리가 불분명하면 상대방과 합의하기 전에 담당 전문가에게 확인하세요.

PDF 저장 후 실제 파일을 다시 엽니다

미리보기에서 총액과 비고를 확인한 뒤 인쇄 대화상자의 PDF 저장 기능을 사용합니다. 저장된 파일을 다시 열어 제목, 표와 합계가 페이지에서 잘리지 않았는지 확인하세요. 파일명에는 문서 종류, 거래처, 날짜와 문서번호를 넣되 불필요한 개인정보를 포함하지 않는 편이 좋습니다.

이메일이나 메신저로 보내기 전 수신자를 다시 확인하고 계좌번호와 연락처가 맞는지 검토하세요. 브라우저 입력 내용은 서버에 저장되지 않지만 생성한 PDF는 사용자의 기기에 남습니다. 공용 컴퓨터에서는 다운로드 폴더와 인쇄 기록을 정리하고 파일 접근 권한을 확인해야 합니다.

수정본과 승인 내역을 별도로 관리합니다

상대방이 품목이나 금액 변경을 요청하면 기존 PDF를 덮어쓰기보다 새 버전으로 저장하고 변경일과 내용을 기록하세요. 문서번호 뒤에 버전을 붙이거나 비고에 이전 문서 대체 여부를 적으면 어느 파일이 최종본인지 구분하기 쉽습니다. 구두 합의만으로 금액을 바꾸지 말고 확인 가능한 방식으로 남기는 편이 안전합니다.

견적 승인, 납품 확인과 지급 완료는 문서 생성기 밖에서 관리해야 합니다. 파일을 보관할 때에는 거래처별 폴더와 접근 권한을 정하고 보존기간과 삭제 기준을 확인하세요. 개인정보와 계좌정보가 포함된 문서를 불필요하게 여러 메신저에 복제하지 않도록 전달 경로도 관리해야 합니다.

상대방이 문서를 열지 못하거나 표가 다르게 보이는 문제를 줄이려면 PDF 저장 후 파일 크기와 페이지 수를 확인하고 일반적인 PDF 뷰어에서도 열어 보세요. 전달 메시지에는 문서번호와 결제기한을 간단히 적되, 민감한 계좌정보를 메시지 본문에 반복하지 않는 편이 안전합니다. 수신 확인이 필요한 거래라면 별도의 확인 절차도 정하세요.

자주 묻는 질문

생성한 문서는 세금계산서인가요?

아닙니다. 일반 견적·청구 양식이며 공식 증빙은 별도 발행 절차가 필요합니다.

부가세 포함 가격은 어떻게 입력하나요?

추가 세액을 더하지 않는 선택을 사용하되 공급가액과 세액을 역산하는 기능은 아니라는 점을 확인하세요.

입력한 거래 정보가 서버에 저장되나요?

아닙니다. 문서 생성은 현재 브라우저에서 처리되며 저장한 PDF는 사용자의 기기에만 남습니다.

PDF가 두 페이지로 나뉘면 어떻게 하나요?

품목과 비고 길이, 인쇄 배율과 여백을 조정하고 저장된 파일을 다시 열어 확인하세요.
